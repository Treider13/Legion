# LEGION — Подключение ESP32 ↔ ADF4351

Логика обеих сторон 3.3 В — подключение напрямую, без делителей (факт M6;
делитель 560Ω/1кΩ нужен только для 5-вольтовых Arduino — F1CJN).

## Распиновка по платам

| Сигнал ADF4351 | ESP32 classic | ESP32-S3/S2 | ESP32-C3/C6/H2 | Направление |
|---|---|---|---|---|
| CLK | GPIO18 | GPIO12 | GPIO4 | МК → модуль |
| DATA | GPIO23 | GPIO11 | GPIO6 | МК → модуль |
| LE | GPIO5 | GPIO10 | GPIO5 | МК → модуль |
| LD (MUXOUT) | GPIO19 | GPIO13 | GPIO7 | модуль → МК |
| CE | GPIO22 | GPIO14 | GPIO10 | МК → модуль |
| VCC | 5 В (стабильное!) | 5 В | 5 В | питание |
| GND | GND | GND | GND | общая земля |

## Аттенюатор PE43702 (опция, фаза 8)

| Сигнал PE43702 | ESP32 classic | ESP32-S3/S2 | ESP32-C3/C6/H2 |
|---|---|---|---|
| CLK | GPIO25 | GPIO15 | GPIO2 |
| SI (DATA) | GPIO26 | GPIO16 | GPIO3 |
| LE | GPIO27 | GPIO17 | GPIO8 |

Цепочка: ADF4351 RF out → PE43702 → нагрузка/антенна. Управление уровнем:
`SET ATT <dB>` (0–31.75 дБ, шаг 0.25 дБ).

## Правила монтажа (факты M1–M8)

1. **Провода ≤10 см**, витая пара с землёй приветствуется. Глитчи на SPI = мусор в регистрах (EngineerZone).
2. **Перед первым включением — прозвонить пины модуля**: на партиях AliExpress маркировка DAT/CLK/LE перепутана (M1). См. module-quirks.md.
3. **Питание 5 В стабильное**; на модуле AMS1117 — просадки недопустимы (M2).
4. **Неиспользуемый SMA-выход — нагрузка 50 Ом** (M5).
5. Питание от внешнего источника чище по спектру, чем от USB (M8; на практике USB допустимо — G4EEV).
6. Если на модуле 100 МГц osc и выход похож на «гребёнку» — отключить его питание (M3, BATC).
