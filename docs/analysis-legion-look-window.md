# LEGION — взгляд 2445…2455 вокруг найденных 2450

Снимок: `c213041`. Код и прошивку этот документ не меняет.

Уточнение замысла (оператор): нашлась частота **2450 МГц** — на усилитель
идёт полоса **2445…2455 МГц**, середина 2450. Это не тон «ровно 2450» и не
заливка 10 МГц шумом. Ниже это сведено с кодом, с сеткой хоста и NIOS
(числа прогнаны), с ADI/Nuand. Без «потом»: пункт либо обязателен для
этого канала на SMA, либо замыслом не обещан и это доказано.

Связанные разборы того же снимка (код тоже не меняли):

- [analysis-legion-intent-complete.md](analysis-legion-intent-complete.md) —
  полный перечень U/R/T/V/F и приёмка без отсрочек;
- [analysis-legion-us-path.md](analysis-legion-us-path.md) — путь
  detect→`dac_streams`→усилитель за микросекунды;
- [analysis-legion-recheck.md](analysis-legion-recheck.md) — первый
  независимый разбор Codex.

## 0. Закрытое определение примера

| Слово оператора | Что это в железе | Что это не есть |
|---|---|---|
| «нашлась 2450» | Текущая стоянка `AIR_FREQ` = 2450 МГц = центр взгляда | Пик FFT внутри окна; герц тона |
| «на усилитель 2445…2455» | Analog RF BW = **10 МГц**, LO RX=TX=2450; IQ с RX этого канала на TX (`lb_gated` → `dac_streams`) | Кирпич с обрывом на 2445.000 / 2455.000; залитый 10 МГц CW |
| «2450 — середина» | \(F \pm W/2\), \(W\) = взгляд = `AIR_BW` | Коридор F1…F2 (коридор только ставит сетку LO) |

Формула канала на усилителе:

\[
\text{TX SMA} \approx [F - W/2,\; F + W/2]
\quad\text{при}\quad F=\texttt{AIR\_FREQ},\; W=\texttt{AIR\_BW}.
\]

Для цифр оператора: \(W = 10\) МГц, \(F = 2450\) МГц.
Оператор **обязан** задать взгляд **10 МГц**. Дефолт продукта 2 МГц
(`FPGA_AIR_BW_DEFAULT_MHZ`, `store.ts` 1543, `LEGION_AIR_BW_HZ=2000000`)
даёт \(2449\ldots2451\), не \(2445\ldots2455\). Это другой взгляд, не баг
сетки.

На усилитель идёт **принятый IQ** в этом аналоговом канале. Пустой край
окна остаётся шумом приёмника. Заполненный спектр 2445…2455 будет только
если в эфире там есть энергия. Тон на 2447 при LO=2450 и взгляде 10
открывает **тот же** канал 2445…2455: детектор \(I^2+Q^2\)
(`legion_detector.vhd`) не измеряет 2450.000.

## 1. Откуда берутся 2445 и 2455 — факты кода

### 1.1 Хост пишет взгляд, не «полосу коридора»

| Шаг | Факт |
|---|---|
| Поле UI | `fpgaAirBwMhz`, подпись «ширина одного взгляда платы и шаг сетки LO (аналоговый фильтр)» (`StartGate.tsx` 243; `ScanPanel.tsx` 147–155) |
| План | `lookMhz = clampAirBwMhz(fpgaAirBwMhz, analog платы)` (`fpgaFastpath.ts` 304–305) |
| Старт | `bwMhz: plan.lookMhz`, `freqMhz: plan.firstMhz`, `fsHz: plan.fsHz` (`store.ts` 1153–1164) |
| fs | `airFsHz(W) = max(round(W·1e6), 520834)` (`fpgaFastpath.ts` 96–99). Взгляд 10 → **10 000 000** Гц |
| NIOS | `BANDWIDTH` RX и TX = `legion_air_bw_hz` иначе 2e6 (`legion_cmds.c` 125–174) |
| NIOS | `FREQUENCY` RX и TX = `AIR_FREQ` (`legion_cmds.c` 128–129, 166–167) |
| Hop | Оба LO одним `legion_hop_lo` (`legion_cmds.c` 429–432 micro; 462–465 x40) |
| Mux | `lb_gated`: данные с RX FIFO на DAC только при `det_active`; каденс valid жив, иначе LMS держит последний сэмпл (`legion_tx_mux.vhd` 137–160) |
| Топ-левел | `dac_streams(0) <= lg_mux_*` (`bladerf-legion.vhd` 1246–1248) |

Коридор F1…F2 **не** задаёт ширину на усилителе. Он задаёт, **какие**
центры стоянок существуют. Ширина на усилителе = взгляд.

Следствие, которое ломает наивное «коридор 2448…2452, взгляд 10»:
коридор уже взгляда → одна стоянка, центр = середина коридора = 2450,
а на усилителе всё равно **взгляд** 2445…2455, не 2448…2452.
Прогон: host `planCenters([2448,2452], 10) = [2450]`; NIOS
`n=1`, `(2448000/2)+(2452000/2)=2450000` кГц. Analog BW при этом
пишется 10e6, не 4e6.

### 1.2 Сетка: когда 2450 вообще становится стоянкой

Одна формула в двух местах, прогон совпал побайтно по кГц.

Хост (`scan.ts` 183–198):

- если `span ≤ look` → один центр `(f1+f2)/2`;
- иначе `n = ceil(span/look)`, `c_i = f1 + look/2 + i·look`, клип к `f2`.

NIOS (`legion_cmds.c` 250–289), комментарий «та же формула»:

- `look_khz = AIR_BW/1000` (0 → дефолт 2 МГц);
- `span ≤ look` → `n=1`, центр `(f1/2)+(f2/2)` (без переполнения uint32);
- иначе `n = (span+look-1)/look`, `c = f1 + look/2 + i·look`.

Прогон на `c213041` (host float и NIOS integer — одно и то же):

| Коридор, МГц | Взгляд | n | Центры | 2450 — стоянка? | На усилителе, если «нашли 2450» |
|---|---|---|---|---|---|
| **2445…2455** | **10** | **1** | **2450** | **да** | **2445…2455** — пример оператора |
| 2448…2452 | 10 | 1 | 2450 | да | всё равно 2445…2455 (взгляд, не коридор) |
| 2450…2450 | 10 | 1 | 2450 | да | 2445…2455 |
| 2445…2455 | **2** (дефолт) | 5 | 2446, 2448, **2450**, 2452, 2454 | да | **2449…2451**, не 2445…2455 |
| 2400…2500 | 10 | 10 | 2405, 2415, …, **2445**, **2455**, …, 2495 | **нет** | 2450 на **стыке** двух взглядов |
| 2440…2460 | 10 | 2 | 2445, 2455 | нет | 2450 на стыке |
| 2430…2470 | 10 | 4 | 2435, 2445, 2455, 2465 | нет | то же |
| 2400…2500 | 2 | 50 | 2401, 2403, …, 2449, 2451, … | нет | 2450 нет даже как центр |
| 2400…2500 | 15 | 7 | 2407.5 … 2452.5 … | нет | UI «2450 и 2465 раздельно при взгляде ≤15» — про **разнос тонов**, не про попадание 2450 в сетку 2400…2500 |

Чтобы пример оператора случился, одновременно:

1. взгляд = **10 МГц** (иначе середина 2450 даёт другую полуширину);
2. сетка ставит стоянку **ровно 2450** — проще всего коридор, который
   целиком влезает в 10 МГц и имеет середину 2450 (типично **2445…2455**).

Коридор 2400…2500 при взгляде 10 **не** даёт стоянку 2450. Энергия на
2450.000 попадёт либо во взгляд 2445 (окно 2440…2450), либо во взгляд
2455 (окно 2450…2460) — в зависимости от того, где стоит LO в момент
детекта. Это не баг формулы, это арифметика `f1 + look/2`.

Текст продукта уже это разделяет: «две частоты ближе взгляда — одно
TX-окно; уже взгляд — 2450 и 2465 как разные стоянки»
(`StartGate.tsx` 238–240; `fpgaFastpath.ts` 270–271). «Нашлась 2450» =
энергия в взгляде, чей **центр** 2450, не «измерили 2450.000».

### 1.3 n=1 для коридора 2445…2455 / взгляд 10

`planOnboardIntercept`: `centers.length==1` → «LO не шагает, гейт N µs»
(`fpgaFastpath.ts` 339–341). NIOS `legion_scan_walk`: `n==1` — return
(`legion_cmds.c` 541–545). Выдержка TURN для одной стоянки не шагает и
не гасит TX. Гашение — спад энергии, Стоп, watchdog.

Для **этого** примера выдержка 0.4 мс не участвует в смене канала.
Она обязательна, когда коридор шире взгляда (2450 → 2465). Путать
выдержку с шириной 2445…2455 нельзя.

## 2. Канал не кирпич 2445.000…2455.000

### 2.1 AD9361 (micro xA4/xA9)

`ad9361_set_rx_rf_bandwidth` / `ad9361_set_tx_rf_bandwidth` — то, что
пишет NIOS командой `BANDWIDTH` (`devices_rfic_cmds.c` 601–609).

ADI no-OS, атрибуты IIO: **`rf_bandwidth` = analog RX/TX filter 3dB
corner frequency, in Hz**
([no-OS AD9361](http://analogdevicesinc.github.io/no-OS/drivers/rf-transceiver/ad9361.html)).
Диапазон канала чипа: от <200 кГц до 56 МГц — тот же потолок, что
каталог Legion (`catalog.ts` 37, `bladerf2_bandwidth_range` 200000…56000000).

Это Butterworth analog LPF, не brick-wall. UG-570: калибровка cutoff,
квантование делителя, BBBW = половина complex BW. На частоте «BW»
сигнал уже около −3 дБ, не −60 дБс. Крутые края даёт FIR из Filter
Wizard, не одна запись `BANDWIDTH`.

libbladeRF прямо пишет: bandwidth лучше держать **ниже** sample-rate,
чтобы не кормить алиасинг (`libbladeRF.h` 1139–1141). При взгляде 10
`airFsHz(10)=10e6` — Nyquist комплекса = 10 МГц, **совпадает** со
взглядом. Края 2445 и 2455 сидят на Nyquist и на −3 дБ LPF сразу.
Честная подпись: «канал с центром 2450 и шириной **порядка** 10 МГц»,
не «ровно −60 дБс на 2444.9».

### 2.2 LMS6002D (x40)

Каталог: программируемые фильтры **1.5…28 МГц** (`catalog.ts` 17;
`BLADERF_BANDWIDTH_MIN/MAX` 1.5e6 / 28e6). Взгляд 10 МГц законен.
Взгляд 0.2 МГц — нет (хост: «x40 ниже 1.5 МГц откажет честно в park»,
`fpgaFastpath.ts` 85). На x40 2445…2455 вокруг 2450 — тот же взгляд 10,
тот же LO на RX и TX (`lms_set_precalculated_frequency` оба модуля,
`legion_cmds.c` 462–465).

### 2.3 FIR на взгляде 10 МГц — не 4x

`bladerf2_sample_rate_range_4x` = 520834…**2083334**
(`bladerf2_common.h` 534–538). Nuand #581 / PR #593: ниже ~2.1 MSPS
без DEC4/INT4 rate не поддержан.

| Взгляд | fs | В зоне 4x? | Что писать в FILTER |
|---|---|---|---|
| 0.2 МГц | 520834 | да | RX DEC4 + TX INT4 **до** SAMPLERATE |
| 2 МГц (дефолт) | 2e6 | да | то же |
| **10 МГц (этот пример)** | **10e6** | **нет** (10e6 > 2083334) | **default**: RX DEC1, TX BYPASS |

INIT сам ставит FIR DEFAULT (`devices_rfic_cmds.c` 178–181;
`BLADERF_RFIC_RXFIR_DEFAULT = DEC1`, `TXFIR_DEFAULT = BYPASS`,
`bladeRF2.h` 182, 196). Legion `legion_air_up` FILTER **не пишет**
(`legion_cmds.c` 124–174). После сессии 0.2 МГц, если кто-то всё же
поставил DEC4, уход на 10 MSPS **обязан** вернуть default — иначе
полоса и fs не те (хост Nuand: `old_low && !new_low` restore default).
На `c213041` этого переключения нет.

128-tap DEC4 на 10 MSPS не нужен и вреден, если остался с прошлой
сессии. Group delay 4x (~16 выходных сэмплов на сторону) в бюджет
**этого** взгляда не входит — при правильном FILTER.

### 2.4 Что именно едет на усилитель

```
эфир 2445…2455 (что есть)
  → AD9361/LMS RX analog LPF (−3 дБ ≈ 10 МГц) + ADC
  → FPGA: I²+Q², 16 сэмплов @ 10 MSPS = 1.6 мкс до решения
  → dcfifo → mux lb_gated (данные режет гейт, valid жив)
  → dac_streams → тот же RFIC DAC
  → TX analog LPF (−3 дБ ≈ 10 МГц)
  → TX SMA → усилитель → 50 Ом
```

NCO / player сюда не входят. NCO — тон на LO, на усилителе одна
несущая 2450, не канал. Host USB IQ — сотни µs…мс, не этот путь
(`architecture.md` 94–104; форум Nuand t=13120, t=5197).

## 3. Два времени на этом канале

| Имя | Число при взгляде 10 / fs=10e6 | Что делает с 2445…2455 |
|---|---|---|
| Гейт детектора | `16 / 10e6 = 1.6 мкс` (`FPGA_US_DET_SHIFT=4`) | Как быстро открыть TX, **уже стоя на 2450** |
| CDC + FIFO | 2 такта + единицы сэмплов | Фаза, не смена полосы |
| AD9361 RF loopback (ориентир EZ) | 94–102 такта @ 20 MSPS → класс ~5 мкс | Сквозь чип, не USB |
| Выдержка TURN | 400 мкс, если n>1 | Смена стоянки 2450→сосед; **не** ширина канала |
| Hop PLL | сотни µs…мс | 2450→2465 — не микросекунды |
| Watchdog | limit=153 @ micro 10e6; `153×65536/10e6 = 1.003 с` | Мёртвый хост гасит TX. Дефолт 61 @ 10e6 = **0.400 с < kick 500 мс** — ARM сгорит среди живого гейта |

Микросекунды замысла — строка «гейт». Не hop. Не «заливка 10 МГц».

Тест в дереве уже знает про 10 МГц и WD: `watchdog_limit_for_fs(10e6, bladerf2)==153`;
«дефолт 61 @ 10 МГц < kick» (`test_legion_fpga.py` 968–971;
`test_orchestrator.ts` 1416–1417). Шлюз пишет limit от `fs_hz`
(`gateway.py` 732–741). Без `fs_hz` — 61, на этом взгляде это дефект
тракта, не косметика.

## 4. Каждая рекомендация — снова фактом, уже против 2445…2455

Колонка «Без этого 2445…2455 на усилителе?» отвечает на уточнение
оператора, не на абстрактный чеклист.

| # | Факт в снимке | Без этого канал 2445…2455 @ 2450? |
|---|---|---|
| **Взгляд=10 в UI и на проводе** | Дефолт 2 МГц → `AIR_BW=2e6` → ±1 МГц. `parseFloat` пустого поля → NaN → clamp → 2 | **Нет.** Получится 2449…2451 |
| **Коридор ставит центр 2450** | 2400…2500 / 10 → 2450 нет в сетке (прогон §1.2) | **Не тот канал.** Энергия 2450 сидит на стыке 2445\|2455 |
| **`AIR_BW` RX+TX = 10e6, readback** | NIOS пишет запрос, читает статику «что просили» (`legion_cmds.c` 692–693), не `ad9361_get_*_rf_bandwidth` | **Не доказано.** Чип мог квантовать cutoff |
| **`AIR_FREQ` RX+TX = 2450e6** | Hop оба; отказ TX-hop → unmute на разных LO (U4, строки 429–435) | На усилителе не 2445…2455 (чужой LO) |
| **fs=10e6, FILTER = default, не DEC4** | 10e6 вне range_4x; INIT default; Legion FILTER не пишет; после 0.2 МГц DEC4 может остаться | Полоса/fs чужие — не 10 МГц взгляд |
| **`lb_gated`, не NCO/player** | NCO — тон на LO (`legion_tx_mux` MODE_NCO) | На усилителе несущая 2450, не канал |
| **Эфир поднят (AIR_PREP / CONTROL)** | Иначе ADC/DAC молчат, гейт гейтит тишину | Нет канала |
| **U1** валидация ARM до эфира | `_air_enable` до SCAN bounds (`gateway.py` 753–758). Отказ «нет F1/F2» не откатывает эфир | Отказной Старт может оставить TX. «Нашла 2450» не начиналось, усилитель уже под током |
| **U2** частичный AIR → STANDBY | `air_is_up` только в конце (`legion_cmds.c` 198); `air_down` no-op если флаг false (221–223) | RX без TX или наоборот — не repeater 2445…2455 |
| **U3** DISARM не врать | `air_down()` без проверки (659–662); шлюз считает CTRL=0 успехом | Стоп не доказал тишину на SMA. Канал «висит» |
| **U4** hop без unmute на разных LO | unmute в ветке fail (433–435) | Для n=1 (коридор 2445…2455) hop не вызывается. Для коридора шире взгляда — усилитель на чужой частоте во время «поиска» |
| **U5** readback SCAN ≠ STATUS | чтение SCAN_* падает в STATUS (`legion_cmds.c` 696); FakeTransport так же; тесты смотрят `._t.regs` | Нельзя проверить, что на плате F1=2445, F2=2455, look=10. Сетка хоста и плата могут разъехаться |
| **U6–U7** `0,4` → 400 мкс | `int(0.4)=0` в `op set`; `parseFloat("0,4")===0` → clamp → 3000 мс; NIOS 0 → 3 с | Для **n=1 не меняет** 2445…2455 (walker не шагает). Для 2450→2465 ломает очередь. Не отмена U6–U7 |
| **R1–R5** FILTER+readback fs/BW | нет FILTER; нет get SAMPLERATE/BANDWIDTH после AIR | Взгляд 10 МГц — запись, не факт чипа. После 0.2 МГц — чужой FIR |
| **T1** WD от фактического fs | 10e6 → 153; без fs_hz → 61 → 0.400 с < kick 500 мс | Гейт 1.6 мкс жив, ARM сгорает через 0.4 с. Канал на усилителе пропадает «сам» |
| **T3** CDC `det_count` на x40 | многобит без синка | Ложный UI/автовозврат. Гейт mux смотрит `det_active` после synchronizer — SMA отдельно |
| **T5** убить USB-handoff | `fpgaHandoff` ставит `fpgaAutoCycle:true` (`store.ts` 1413); Старт сейчас пишет false (1096) | Host retune ≠ этот канал за мкс. Уничтожает замысел |
| **V1** водопад = взгляд | `applyLook`: полуширина `look/2`, гаусс, не кирпич (`waterfall.ts` 80–101). FrequencyField рисует `fpgaMhz ± look/2` (190–195) | Не ломает SMA. Без подписи оператор читает 2445…2455 как спектр |
| **V3** герц внутри окна | детектор не FFT | **Не дефект.** Тон 2447 открывает тот же 2445…2455. Новый FFT — другой продукт |
| **n=1 ARM жив** | walker return | **Не дефект.** Канал должен жить, пока энергия и нет Стоп |
| **F1** SC16Q11 | тап детектора в тех же кодах | Порог с другой шкалы откроет гейт на шум или не откроет на цель — канал врёт |
| **F3** тишина = нули с valid | mux 5–7, 137–160 | DISARM/нет энергии не должны держать последний сэмпл на 2450 |
| **L1–L6** образ legion + STA + libad936x + park | hosted нет mux 0x80; micro без libad936x AIR отказ | Прошивка «не встала» — канала нет |
| **E1–E6 как сейчас** | E2 SKIP кабеля = ALL PASS (`acceptance_bench.py` 197–200) | **Не принимают** 2445…2455. Расчёт ≠ спектр на SMA |
| ADI `sync_event` вместо heartbeat | toggle+2FF уже есть | **Не обязателен** для этого канала |
| VUnit вместо GHDL | 8 TB уже на GHDL | Не блокер |
| ESP32 / ADF4351 | другой тракт, запрет смеси (`architecture.md` 71–76) | Не этот канал |
| Tone Nuand / foxhunt | стимул на стенде | Стимул, не замена `lb_gated` |

U4, U6–U7 не отменяются примером n=1: система обязана ещё и обходить
коридор шире взгляда. Для **доказательства именно 2445…2455** достаточно
одной стоянки 2450. Для **рабочей системы по замыслу** — весь столбец.

## 5. Что сделать (один список, этот режим)

Ни SKIP, ни «потом». Порядок — зависимость.

### 5.1 Контракт (зафиксировать в приёмке, не в маркетинге)

- Взгляд \(W\) МГц, LO \(F\) → на RX и TX канал \(F \pm W/2\).
- Пример: \(W=10\), \(F=2450\) → 2445…2455.
- Не тон. Не кирпич. Не USB-handoff. Не «коридор равен каналу».
- «Нашлась 2450» = `AIR_FREQ` текущей стоянки, не FFT.

### 5.2 Красные тесты на `c213041` (обязан покраснеть)

1. ARM с `scan_enable` без F1/F2: эфир остаётся (U1). Сейчас тест ловит
   только `ok:false` (`test_legion_fpga.py` 1125–1127).
2. SCAN read = STATUS, не последние SCAN_* (U5).
3. Нет FILTER-переключения 0.52 MSPS ↔ 10 MSPS (R1).
4. `set scan_dwell_ms 0.4` / поле `0,4` → не 400 мкс (U6–U7).
5. SKIP кабеля в E2 не растит fails → ALL PASS.

Пока 1–5 зелёные на заглушках, «канал 2445…2455» нечем доказывать.

### 5.3 Код тракта (после красных тестов)

Валидация до AIR; откаты частичного AIR; честный DISARM; hop без unmute
на разных LO; `0,4`→400 мкс; FILTER 4x **только** в [520834, 2083334],
на 10e6 — default; readback LO/fs/BW/FILTER с чипа; walker и WD от
**прочитанного** fs; закрыть `fpgaHandoff`.

На взгляде 10 отдельно: ARM всегда несёт `fs_hz=10000000` и
`bw_mhz=10`, WD_LIMIT=153 (micro) / 305 (x40, `tx_clk=2·fs`).

### 5.4 Образ

Quartus 23.1.1 `legionxA4` (x40/xA9 по плате), STA WNS/TNS≥0, hash
отчёта = файл = прошитое, NIOS с `BLADERF_NIOS_LIBAD936X`,
`ping.legion===true`. Hosted = не этот режим.

### 5.5 Стенд — единственное доказательство уточнения

**Стенд A (пример оператора).** Взгляд 10 МГц, коридор **2445…2455**,
одна стоянка 2450, `lb_gated`, 50 Ом, кабель TX→RX с аттенюатором
**или** второй приёмник. Нет кабеля = FAIL.

| Стимул на RX | Ожидание на TX SMA |
|---|---|
| Тон/энергия **2450** или **2447** (внутри взгляда) | Тот же **канал**, центр 2450, ширина порядка 10 МГц; не одна несущая, если в эфире не одна; не кирпич |
| Тон **2430** (вне взгляда, далеко за −3 дБ) | Гейт закрыт / нет ретрансляции |
| Нет стимула | Нули с каденсом, не «последний сэмпл» |
| Стоп / watchdog (~1.0 с @ 10 MSPS, limit 153) | Тишина за измеренный интервал |
| Отказной Старт (нет F1/F2) | Нет несущей |
| Readback | LO≈2450e6, BW≈10e6 (допуск квантования ADI), fs=10e6, FILTER=default (не DEC4) |

**Стенд B (сетка не врёт).** Коридор 2400…2500, взгляд 10: стоянки
2405…2495, **2450 нет**. Энергия на 2450.000 не подписывается как
«нашли 2450». Соседние взгляды 2445 и 2455 — разные окна
(2440…2450 и 2450…2460).

**Стенд C (дефолт не подменяет пример).** Взгляд 2 МГц, коридор
2445…2455: при стоянке 2450 на усилителе **2449…2451**. Если спектр
похож на 10 МГц — BW не тот.

**Стенд D (коридор шире).** Энергия во взгляде 2450 держит 2445…2455;
TURN 0.4 мс → шаг на соседний центр сетки; 2450 и 2465 раздельно только
если взгляд ≤15 МГц **и** оба есть в сетке (при 2400…2500 / 10 оба есть:
2445, 2455, 2465 — 2450 по-прежнему не центр).

**Стенд E (FIR-переключение).** Сессия 0.2 МГц (DEC4/INT4) → сессия
10 МГц: FILTER вернулся в default, спектр 10 МГц, не «узкий 4x».

Пункт 5.5.A — единственное доказательство фразы «2445…2455 вокруг 2450».
Без спектра на SMA это не рабочая система. Расчёт §2–§3 без стенда —
не приёмка.

Мощность на 50 Ом — цифра в отчёте. Галочка `sdrLoadOk` (`store.ts`
1067–1069) измерением не является.

### 5.6 Soak

После зелёных A–E — 8 ч `lb_gated` в 50 Ом (`soak_bench.py`). Самовозбуд
с антенной на TX — физика (`fpga/README.md` 205–206), не патч детектора.
Утечка своего TX в RX держит гейт (`fpgaFastpath.ts` 40–43): СТОП и
watchdog обязательны всегда.

## 6. Что нельзя обещать даже после полного перечня

Это закрытие, не хвост.

| Обещание | Почему нет |
|---|---|
| Точный герц тона внутри 2445…2455 | Детектор \(I^2+Q^2\), USB IQ запрещён замыслом |
| Кирпич на 2445.000 / 2455.000 | ADI `rf_bandwidth` = analog **3 dB** corner; fs=BW=10e6 на Nyquist |
| «Нашли 2450» в коридоре 2400…2500 при взгляде 10 | Сетка не содержит 2450 (прогон §1.2) |
| Дефолтный взгляд 2 МГц = этот пример | Даёт ±1 МГц |
| Микросекундный прыжок 2450→2465 | PLL, не гейт |
| Путь через программу на ноутбуке | Форум Nuand t=13120 / t=5197; сам продукт вычеркнул USB из круга |
| Модель PA / «безопасно 1 Вт» | В репозитории нет; есть только измерение на 50 Ом |
| Hosted FPGA | Нет mux 0x80 |

## 7. Прямой ответ на уточнение

**Да, фраза «нашлась 2450 — на усилитель 2445…2455, середина 2450»
однозначна и уже есть в продукте как формула взгляда:** analog BW =
взгляд = 10 МГц, LO = 2450, TX = принятый IQ этого канала через
`lb_gated`. Это аналоговый канал с мягкими краями, не тон и не кирпич.

**Чтобы это случилось, оператор обязан:** взгляд 10 МГц; коридор, который
ставит центр 2450 (типично 2445…2455). Иначе либо ±1 МГц (дефолт 2),
либо 2450 на стыке (2400…2500 / 10).

**Нет, на `c213041` это не рабочая система:** FILTER/readback/отказы
управления/образ/SMA не доказаны; приёмка умеет ALL PASS без кабеля;
дефолт 2 МГц молча подменяет пример; leftover DEC4 после узкого окна
ломает 10 MSPS; WD без `fs_hz` на 10 МГц короче kick.

Полный закрытый список = §5 + U1–U7 + R1–R5 + T1/T3/T5 + L1–L6.
Откладывать стенд A, FILTER на границе 4x, честный DISARM или сверку
образа нельзя: без любого из них на усилителе либо нет 2445…2455,
либо есть враньё, что они есть.
