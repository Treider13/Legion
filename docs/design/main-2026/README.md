# LEGION — главное окно

Макеты SitRoom / NORAD / Houston сняты с продукта: это костюм, не пульт.

Рабочее главное окно — в приложении (`app/src/App.tsx`):

1. Живой 3D-глаз (`Scene` / `CyborgEye` не менялись).
2. Полоса частот из `scanBins` / телеметрии.
3. **Запустить** → коридор F1–F2 и тип сигнала (`WAVE_CATALOG`).
4. **Продолжить** → скан и TX на усилитель (SDR) или коридор ESP32.
5. Лаборатория — **Настройки**. FPGA ARM остаётся там.

Старые PNG в этой папке — архив отвергнутых направлений.
