# LEGION — ближайшие ровесники (не C-UAS, а тот же класс прибора)

Предыдущий разбор ([analysis-related-repos.md](analysis-related-repos.md)) смотрел
проекты **по теме РЭБ**. Этот — проекты **того же класса железа и ПО**, что
LEGION: лабораторный синтезатор 35 МГц–4.4 ГГц и/или SDR RX/TX на bladeRF.
Код не меняем и не копируем. Дата: 2026-08-31. Звёзды — живые.

## Короткий ответ

**Одного репозитория «как LEGION целиком» нет.** Мы склеили два разных
прибора в одном Control:

| Половина LEGION | Ближайший открытый ровесник | Кто сильнее как продукт |
|---|---|---|
| ESP32 + ADF4351 + коридор/HOP/CHIRP + desktop | **RFGEN44** ([circuitvalley/ADF4351_USB_RF_GEN](https://github.com/circuitvalley/ADF4351_USB_RF_GEN), 46★) | RFGEN44 — законченный *прибор* (HID, своя плата, sync). LEGION — богаче *режимами и тестами* |
| SDR скан + TX + bladeRF | **SDRangel** ([f4exb/sdrangel](https://github.com/f4exb/sdrangel), 3948★) | SDRangel сильнее как рабочая станция RX/TX. LEGION сильнее в одном узком месте: FPGA `lb_gated` detect→TX за микросекунды |

«Чем лучше будет» LEGION — не стать третьим Gqrx и не стать клоном RFGEN44.
Имеет смысл взять у ровесников **три дыры**, которых у нас нет как у прибора:
драйверless USB (HID), sync к анализатору, нормальный водопад скана. Остальное
у больших SDR — другой продукт.

---

## 1. Почему клона нет

Типичный открытый проект закрывает **один** слой:

- драйвер ADF4351 (dfannin, pyadf435x, PE5PVB);
- USB-генератор без сканера (RFGEN44, Electro-resonance, siggen4351);
- приёмник со спектром (Gqrx, SDR++, QSpectrumAnalyzer, SigDigger);
- полный SDR RX+TX (SDRangel, отчасти SDR++);
- FPGA на bladeRF под другую задачу (bladeRF-wiphy = Wi-Fi модем; bladeRF-shd = детектор дыр спектра).

Цикл LEGION «сканер нашёл пик → handoff LO → ретрансляция в FPGA / волна на
усилитель» + параллельный тракт ADF4351 на ESP32 в одном UI — уникальная
сборка. Уникальность ≠ превосходство: две половины по отдельности у
ровесников зрелее.

---

## 2. Ближайший по синтезатору: RFGEN44

**Репозиторий:** https://github.com/circuitvalley/ADF4351_USB_RF_GEN  
**Железо:** PIC16F1459 + ADF4351, своя PCB, Crowd Supply / Tindie.  
**ПК:** Qt5 + HIDAPI, Win/Linux/macOS, Python/MATLAB через raw HID.  
**Лицензия GUI:** CC BY-NC-ND 4.0 — **смотреть можно, код/схемы в LEGION
не переносить** (уже отмечено в [REFERENCES.md](REFERENCES.md)).

### Где RFGEN44 лучше как прибор

| Что | У них | У нас |
|---|---|---|
| Подключение к ПК | USB HID, без COM-порта, без драйвера, без «какой ttyUSB» | USB-UART / Web Serial / WiFi / BLE — гибко, но на Windows это порт и разрешения |
| Железо | Спроектированная плата, BOM, корпусный модуль | AliExpress-модуль + Dupont; грабли пинов — наш SELFTEST |
| Sync со спектроанализатором | AUX sync in/out: tracking source к SA / осциллографу | Нет аппаратного маркера шага коридора |
| Внешняя опора | Разъём на плате | Хаки модуля (R5/R8), описаны в module-quirks |
| Несколько приборов на одном ПК | HID + LED identify | Один serial / один шлюз |
| Поставка | AppImage, Windows binary, udev-правило в репо | Сборка из исходников, `setup.sh` |

Это разница «лабораторный прибор, который продают» vs «стенд, который собирают».

### Где LEGION уже сильнее (синтезатор)

| Что | RFGEN44 | LEGION |
|---|---|---|
| Сетка | Реклама 10 кГц | FRAC/INT, тесты против даташита, вектор 2175 МГц |
| Режимы | Sweep + hop | SWEEP / HOP / CHIRP / GLIDE / FM + 31 baseband-волна на SDR |
| Уровень | 4 ступени чипа | PE43702 + `CAL LEVEL` (разомкнутая) |
| Диагностика | Identify / EEPROM | SELFTEST (powerdown / polarity / MUXOUT) |
| Контроллер | PIC16, USB-only | 6 плат ESP32, NVS, OTA, WiFi AP, BLE |
| Тесты | нет сопоставимого native-набора | 57 векторов регистров, фазз парсера, GUI smoke |
| SDR | нет | сканер + FPGA-ревизия |

**Итог по этой половине.** Если цель — «коробка 35 М–4.4 Г на стол, sweep,
без ноутбучных драм», RFGEN44 *как изделие* лучше. Если цель — «стенд с
честной математикой чипа, калибровкой и двумя трактами» — лучше наш софт,
хуже наше железо и USB HID.

Коммерческий потолок того же чипа — Windfreak SynthNV/SynthUSB (калиброванный
уровень на десятки дБ, шаг 0.1 Гц). Это не открытый код; ориентир по
прибору, не репозиторий для заимствования.

## 3. Второй синтезатор-ровесник: siggen4351 (dfannin)

**Репозиторий:** https://github.com/dfannin/siggen4351 (24★, MIT).  
Arduino Nano + модуль SV1AFN + **своя схема**: OCXO 100 МГц, автопереключение
на внешний GPSDO 10 МГц, клавиатура, энкодер, LCD, USB. Библиотека регистров
того же автора уже в нашем реестре (`dfannin/adf4351`).

**Лучше нашего железа:** опора лабораторного класса и ручное управление без
ПК. **Хуже нашего софта:** нет коридора/CHIRP как у нас, нет desktop-оркестратора,
нет SDR. Для LEGION это референс **тракта опоры** (OCXO/GPSDO), не UI.

Electro-resonance/ADF4351-USB-Serial (6★, MIT) — ближе к нашей прошивке по
GLIDE/FM; режимами мы уже обогнали, железа у них тоже «модуль + MCU».

## 4. Ближайший по SDR: SDRangel

**Репозиторий:** https://github.com/f4exb/sdrangel (3948★, GPL-3.0).  
C++/Qt. RX и TX: bladeRF 1/2, HackRF, Lime, Pluto, Airspy, RTL-SDR, USRP и др.
Плагины каналов, Main Spectrum, remote UDP+FEC, REST API, запись I/Q.

### Где SDRangel лучше

| Возможность | SDRangel | LEGION |
|---|---|---|
| Спектр | водопад, маркеры, persistence, несколько окон | кольцо/глаз + список пиков energy-detection, не приборный SA |
| Демодуляция | AM/FM/SSB и десятки канальных плагинов | нет (мы не приёмник связи) |
| Запись I/Q | штатно | нет |
| TX как рабочая станция | модуляции, файлы, несколько стоков | 31 волна с хоста + CW + FPGA loopback |
| Удалёнка | REST + remote source/sink | SoapyRemote / свой шлюз на USB3 |
| Зрелость драйверов bladeRF | годы плагинов v1 и micro | свой `sdr_worker` + официальные образы + ревизия `legion` |

На широкой полосе обзора **QSpectrumAnalyzer** (1445★, бэкенды soapy_power /
hackrf_sweep / rtl_power) ещё удобнее водопада, чем наш скан. **SDR++**
(6290★) — современнее RX-UI. **SigDigger** (2880★) — сильнее как инспектор
неизвестного сигнала (созвездие, baud). **URH** (12k★) и **FISSURE** (2k★) —
разбор протоколов, не генератор.

### Где LEGION лучше (узко)

SDRangel **не делает** наш цикл FPGA+СКАНЕР: пик → парковка LO → `lb_gated`
RX→TX за микросекунды с порогом из шумовой полки и автовозвратом. У них
host USB ставит частоту и гоняет I/Q — это сотни микросекунд…миллисекунды,
и нет first-class «перехват живого пика». Ревизия `legion` + NIOS AIR на
micro — наш зазор, не их.

GPL-3.0: смотреть архитектуру можно; тащить плагины в Tauri нельзя без смены
лицензии всего приложения. Не копируем.

## 6. Чем LEGION *будет лучше*, если брать идеи (не код)

Приоритет — дыры, которые ровесники уже закрыли как прибор. Без смены миссии.

### Имеет смысл (железо / UX прибора)

1. **USB HID или CDC с постоянным VID/PID и udev в комплекте** — урок RFGEN44.
   Сейчас «найди `/dev/ttyUSB0`» — слабое место стенда, не математики чипа.
2. **AUX sync шага коридора** (GPIO импульс на каждый dwell) — tracking source
   к TinySA / SA. Без этого калибровка уровня и проверка гармоник — руками.
3. **Разъём внешней опоры 10 МГц** как у siggen4351 / RFGEN44, не выпаивание
   R5/R8 на AliExpress-плате. OCXO/GPSDO сразу делает нас ближе к лабораторному
   LO, чем любой софт.
4. **Водопад скана** как у QSpectrumAnalyzer / SDRangel Main Spectrum: история
   пиков во времени, не только текущий список. Energy-detection можно оставить;
   не хватает *глаза прибора*.
5. **Запись куска I/Q** по кнопке (как SDRangel) — для разбора «что поймали»,
   не для эфира.

### Не имеет смысла (другой продукт)

- Демодуляторы и плагины SDRangel — это приёмник связи, не наш генератор.
- Копировать Qt GUI RFGEN44 (CC BY-NC-ND) или GPL-плагины в Tauri.
- PortaPack-приложения и любые hop/jam-таблицы.
- Делать «как Windfreak» калиброванный −130 дБм на ADF4351 — физика чипа
  (+5 дБм, 4 ступени) этого не даёт; нужен другой синтезатор / АРУ
  ([analysis-upgrade.md](analysis-upgrade.md)).

### Уже лучше, не отдавать

- Разделение трактов SDR vs ESP32 и запрет мешать их (`modeConflict`).
- FPGA+СКАНЕР / solo / allowlist / RF OFF по умолчанию.
- Тестовая дисциплина регистров и честные отказы (FAKE park → нет ARM).
- Словесный протокол и 6 плат ESP32.

## 7. Одна фраза «какой проект лучше»

- **Купить готовый USB-генератор на ADF4351** — лучше RFGEN44 (или Windfreak,
  если нужна калибровка уровня).
- **Слушать эфир, демодулировать, писать I/Q** — лучше SDRangel / SDR++ /
  SigDigger, не LEGION Control.
- **Стенд «дешёвый 4.4 ГГц + bladeRF с µs-релеем + свои тесты»** — ближе
  нашего сочетания нет; дыры прибора (HID, sync, опора, водопад) как раз
  то, чем ровесники нас обходят.

Код ровесников в `app/` / `firmware/` / `fpga/` не берём. Этот файл —
карта, не план внедрения.
