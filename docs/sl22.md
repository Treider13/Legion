# LEGION ↔ HTOOL SL22

Второй транспорт в desktop-приложении: **USB HTOOL SL22**. ESP32 и модуль
ADF4351 в этом режиме **не используются**. Выбор в панели «СВЯЗЬ» переключает
путь; старый `USB ESP32 (ADF4351)` остаётся как был (`\n`, ASCII, LOCK с LD).

## Как нажать в UI

1. Транспорт `USB HTOOL SL22` (только Tauri: мост открывает COM через тот же
   serial-плагин). Порт Type-C прибора (`COM*` / `/dev/ttyACM*`).
2. ПОДКЛЮЧИТЬ — первая команда `*IDN?\r\n` (вход в SCPI, иначе прибор не
   слушает остальные). Если порт ответил `ERR …` — это ASCII прошивки LEGION
   (не тот COM).
3. Мощность: четыре кнопки UI → ступени **LOPW 0, 1, 2, 3** (не дБм прибора).
   В гайде: P0…P7, 0 ниже 7; калибровки дБм нет — кнопки подписаны P0–P3.
4. Коридор только **ОБЗОР (SWEEP)**. Пример 2300–2500, шаг **1000 кГц** (= 1 МГц
   на `POINt`), выдержка 10 мс. HOP/CHIRP/ATT/SELFTEST скрыты: перевода нет.

Тракт RF: SL22 → ФНЧ → AT-6S-2W → PA → нагрузка 100 Вт.

## Что уходит на провод

Только строки из Python-класса гайда (ниже). Официальный PDF с htool.net.cn
при разработке не открывался (таймаут).

| LEGION (как в UI) | На COM (`\r\n`) |
|---|---|
| connect / `HELLO` | `*IDN?` (клиенту — синтетический `OK LEGION SL22 …`) |
| `SET FREQ 2475.000` | `GENErator:POINt 2475.000` (RF сам не включается) |
| `RF ON` / `RF OFF` | `GENErator:STATus ON` / `OFF` |
| `SET POWER 5` | `FREQuency:LOPW 3` |
| `SET POWER -4` | `FREQuency:LOPW 0` |
| `SWEEP START 2300 2500 STEP 1000 DWELL 10` | `GENErator:POINt 2300.000` затем `STATus ON`; дальше хост `POINt` |
| `STOP` | `GENErator:STATus OFF` |
| `STATUS?` | на COM ничего; JSON моста, `lock: 0` |

Диапазон: **45–22600 МГц** (тело гайда + даташит TI LMX2820). Заголовок той же
статьи пишет «22 MHz» — это не даташит чипа. Разрешение гайда: **1 кГц**
(`POINt` с тремя знаками).

В SCPI SL22 **нет lock-detect**. `LOCK=` не пишем.

`CYCLe` / `SINGle` мост **не шлёт**:

- `SINGle start,stop,step,t_ms` — один проход, потом RF гаснет (не коридор LEGION).
- `CYCLe start,stop,t_ms` — в **сериализованной** строке гайда шага нет, хотя
  аргумент `step` в Python принимается. Четыре поля — домысел.

Коридор: хост повторяет `engine_sweep_next` и ставит `POINt`. Порядок как в
примере гайда: частота, потом `STATus ON` (не наоборот — иначе вспыхнет старая
частота). Джиттер USB/таймера ПК ≠ аппаратный цикл.

Запросы `POINt?` / `STATus?` / `LOPW?` в классе есть; мост их не читает
(формат ответа на живом приборе не снят).
