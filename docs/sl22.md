# LEGION ↔ HTOOL SL22

Режим в приложении: **USB HTOOL SL22**. ESP32 и плата СКБ ADF4351 в этой ветке
не участвуют. Частоту и коридор ставит сам прибор по SCPI.

## Как нажать в UI

1. Транспорт `USB HTOOL SL22`, порт Type-C прибора (`COM*` / `/dev/ttyACM*`).
2. ПОДКЛЮЧИТЬ — на провод уходит `*IDN?` (вход в SCPI).
3. Частота / RF / мощность (−4/−1/+2/+5 → ступени LOPW 0/2/4/6).
4. Коридор только **ОБЗОР (SWEEP)**. Пример 2300–2500, шаг **1000 кГц** (= 1 МГц
   на SL22), выдержка 10 мс. HOP/CHIRP прибор не умеет.

Тракт RF: SL22 → ФНЧ → AT-6S-2W → PA → нагрузка 100 Вт.

## Что уходит на провод

| LEGION | SCPI (`\r\n`) |
|---|---|
| `HELLO` | `*IDN?` |
| `SET FREQ 2475.000` | `GENErator:POINt 2475.000` |
| `RF ON` / `OFF` | `GENErator:STATus ON` / `OFF` |
| `SET POWER +5` | `FREQuency:LOPW 6` |
| `SWEEP START 2300 2500 STEP 1000 DWELL 10` | `GENErator:CYCLe 2300.000,2500.000,1.000,10` затем `STATus ON` |
| `STOP` | `GENErator:STATus OFF` |

Диапазон перевода: **45–22600 МГц**. LOCK синтетический (`LOCK=1`): у SL22 нет LD.

`CYCLe` шлём с **четырьмя** полями (старт, стоп, шаг МГц, мс). В чужом Python
шаг у цикла забыт — без него коридор 1 МГц потеряется. Если прибор отвергнет
4 поля, проверить на COM и поправить `app/src/sl22/map.ts`.

## Источники (не даташит ADI)

Разбор SCPI + Python-класс (2026), реклама «国商技术 SL22», даташит TI LMX2820
(полоса 45 МГц–22.6 ГГц, FOM −236 — не шум на SMA). Официальный PDF с
htool.net.cn при разработке не был доступен.

Не путать с модулями «SL22» на MAX2871 до 6 ГГц — другой товар.
