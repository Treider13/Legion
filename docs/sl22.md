# LEGION ↔ HTOOL SL22

Второй транспорт в desktop-приложении: **USB HTOOL SL22**. ESP32 и модуль
ADF4351 в этом режиме **не используются**. Выбор в панели «СВЯЗЬ» переключает
путь; старый `USB ESP32 (ADF4351)` остаётся как был (`\n`, ASCII, LOCK с LD).

## Как нажать в UI

1. Транспорт `USB HTOOL SL22` (только Tauri: мост открывает COM через тот же
   serial-плагин). Порт Type-C прибора (`COM*` / `/dev/ttyACM*`).
2. ПОДКЛЮЧИТЬ — на провод уходит `*IDN?\r\n` (вход в SCPI).
3. Мощность: четыре кнопки UI → ступени **LOPW 0, 1, 2, 3** (не дБм прибора).
   В гайде: P0 ниже, P7 выше; калибровки дБм нет — кнопки подписаны P0–P3.
4. Коридор только **ОБЗОР (SWEEP)**. Пример 2300–2500, шаг **1000 кГц** (= 1 МГц
   на `POINt`), выдержка 10 мс. HOP/CHIRP/ATT/SELFTEST в UI скрыты: перевода нет.

Тракт RF: SL22 → ФНЧ → AT-6S-2W → PA → нагрузка 100 Вт.

## Что уходит на провод

Только команды, которые есть в разборе SCPI (Python-класс / гайд 2026).
Официальный PDF с htool.net.cn при разработке недоступен.

| LEGION (как в UI) | На COM (`\r\n`) |
|---|---|
| `HELLO` | `*IDN?` (ответ прибора в журнал не подставляется; клиенту — синтетический `OK LEGION SL22 …`) |
| `SET FREQ 2475.000` | `GENErator:POINt 2475.000` |
| `RF ON` / `RF OFF` | `GENErator:STATus ON` / `OFF` |
| `SET POWER 5` | `FREQuency:LOPW 3` |
| `SET POWER -4` | `FREQuency:LOPW 0` |
| `SWEEP START 2300 2500 STEP 1000 DWELL 10` | `GENErator:STATus ON`, далее хост по таймеру `GENErator:POINt` |
| `STOP` | `GENErator:STATus OFF` |
| `STATUS?` | на COM ничего; JSON со стороны моста, `lock: 0` |

Диапазон перевода частоты: **45–22600 МГц** (тексты SL22 + даташит TI LMX2820).
У SL22 в SCPI **нет lock-detect** — поле `LOCK=` в `SET FREQ` не пишем,
в статусе `lock: 0`. Это не «захват ФАПЧ».

`GENErator:CYCLe` / `SINGle` мост **не шлёт**. В сериализованном примере
гайда у `CYCLe` нет шага (`start,stop,t_ms`); четыре поля — домысел.
Коридор LEGION бесконечный и с шагом из UI: хост повторяет
`engine_sweep_next` (`cur += step; если cur > f2 → f1`) и ставит точку
через `POINt`. Джиттер USB/таймера ПК ≠ аппаратный цикл прибора.

Не путать с модулями «SL22» на MAX2871 до 6 ГГц — другой товар.
